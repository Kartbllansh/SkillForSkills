# SkillForSkills

Найдите в переписке с ИИ полезные рабочие методы и превратите их в персональные скиллы — инструкции для новых задач.

Анализатор разбирает один чат или архив: какие правила вы задаёте, как проверяете результат и какой порядок работы хотите сохранить. Например, способ разбора интервью с подтверждением выводов цитатами можно закрепить для следующих интервью или передать коллеге.

Основанием для рекомендации могут быть меньше повторных объяснений и исправлений, понятная проверка результата или передача метода другому человеку. Для каждого предложения анализатор показывает, какие фрагменты переписки его подтверждают и зачем нужен отдельный скилл.

## Какую версию выбрать

Все четыре файла самостоятельны: скачайте нужный `.md` и приложите к чату с ИИ. Если интерфейс не принимает файлы, вставьте содержимое инструкции текстом.

| Версия | Когда использовать | Результат |
|---|---|---|
| [Один чат — full](skills/analyze-one-chat.md) · 0.4.1 | Нужен подробный разбор одного диалога | Одна основная рекомендация с объяснением метода и пользы |
| [Один чат — lite](skills/analyze-one-chat-lite.md) · 0.1.1 | Нужен короткий разбор одного диалога или законченного эпизода | Не более одной рекомендации, меньше этапов анализа |
| [Архив — full](skills/analyze-chatgpt-archive.md) · 0.3.1 | Нужно сопоставить методы из разных разговоров | До пяти рекомендаций, учёт просмотренного и продолжение обзора |
| [Часть архива — lite](skills/analyze-chatgpt-archive-lite.md) · 0.1.1 | Хотите начать с небольшой группы диалогов | Не более одной рекомендации по выбранной части |

Для первого знакомства начните с одного чата. Full подходит для подробного анализа; lite сокращает инструкцию, число этапов и объём материала за один проход.

## Быстрый старт: один чат

1. Скачайте [full](skills/analyze-one-chat.md) или [lite](skills/analyze-one-chat-lite.md).
2. Откройте нужный чат и добавьте инструкцию. Если история ему недоступна, передайте выбранный диалог текстом, сохранив ваши сообщения и ответы ассистента.
3. Отправьте:

> Примени приложенный скилл к этому диалогу. Покажи одну обоснованную возможность для персонального скилла. Если отдельный скилл не нужен, объясни почему и предложи помощь с более простыми рекомендациями. Создавай файл скилла только после моего подтверждения.

Анализатор покажет найденный метод, основание из переписки и ожидаемую пользу. После вашего подтверждения подготовит самостоятельный `.md` для новых задач. Если сохранение файлов недоступно, выдаст текст для самостоятельного сохранения.

## Анализ архива

Получите выгрузку истории ChatGPT и приложите её вместе с [архивным full](skills/analyze-chatgpt-archive.md). Для первого небольшого разбора выберите [archive lite](skills/analyze-chatgpt-archive-lite.md).

Для full:

> Примени приложенный скилл к архиву моих чатов. Покажи до пяти обоснованных возможностей для персональных скиллов и укажи, какая часть архива рассмотрена. Если подходящих вариантов нет, объясни причину и предложи помощь с более простыми рекомендациями. Создавай файлы скиллов только после моего подтверждения.

Для lite:

> Примени приложенный archive lite к небольшой части архива. Покажи, какие диалоги рассмотрены, и не более одной обоснованной возможности для персонального скилла. Если оснований нет, объясни почему и предложи помощь с более простыми рекомендациями. Файл скилла создавай только после моего подтверждения.

Full рассматривает архив частями, сопоставляет методы между чатами и сохраняет точку продолжения доступными средствами. Если обзор прерван, напишите «продолжи». Lite выполняет ограниченный разбор выбранной части.

## Если модель менее мощная или контекст небольшой

Начните с **lite и одного законченного диалога**, если используете небольшую локальную модель — например, [Llama 3.2 3B](https://ollama.com/library/llama3.2:3b), [Qwen3 4B](https://ollama.com/library/qwen3:4b) или [DeepSeek-R1 1.5B](https://ollama.com/library/deepseek-r1:1.5b). Такой же подход полезен при небольшом доступном контексте. В Ollama выбор режима зависит от запущенной модели и настроек.

**Сначала проверьте готовые части выгрузки.** Распакуйте ZIP и найдите `conversations.json` или пронумерованные `conversations-000.json`, `conversations-001.json` и далее. Если файлов несколько, передавайте их анализатору по одному: каждый может содержать группу чатов. Повторно упаковывать их в ZIP не нужно. Дополнительно делите файл только тогда, когда выбранная среда не справляется с такой частью.

1. Для одного диалога выберите [one-chat lite](skills/analyze-one-chat-lite.md), для небольшой группы — [archive lite](skills/analyze-chatgpt-archive-lite.md).
2. Если диалог длинный, возьмите одну законченную задачу вместе с постановкой, уточнениями и ответами.
3. Если готовая часть выгрузки слишком велика, подготовьте меньшие текстовые части: сохраняйте целые диалоги или законченные задачи, роли, порядок сообщений и метки источников. Если у ИИ есть инструменты чтения архива и создания файлов, он может подготовить части сам. Без них начните с текста одного выбранного диалога.
4. Каждую следующую часть рассматривайте в новом чате с той же lite-инструкцией. Нумеруйте части и сохраняйте результаты: одна длинная переписка со всеми частями снова заполняет контекст.

Пример запроса для подготовки частей в среде с нужными инструментами:

> Подготовь из архива небольшие пронумерованные текстовые части для отдельных запусков lite. Сохраняй целые диалоги; длинные дели по законченным задачам с необходимым контекстом. Сохрани роли и метки источников. Перечисли содержимое частей и оставшийся материал.

Пример анализа одной части:

> Примени приложенный archive lite только к части 01. Укажи просмотренные диалоги и предложи не более одного обоснованного скилла. Если оснований нет, объясни причину. Файл создавай только после моего подтверждения.

### Ограничения

- Для ZIP нужны инструменты чтения архива. Если их нет, передайте доступный текст переписки. Произвольное разрезание ZIP или JSON по размеру не заменяет подготовку текстовых частей.
- Вывод lite относится только к выбранному материалу. Он может пропустить метод, который проявляется при сопоставлении разных частей. Отдельные разборы не равны полному обзору архива.
- Проверьте, что основания рекомендации есть в исходных сообщениях. Несколько правок одного результата не означают несколько независимых выполнений задачи.

## Если отдельный скилл не нужен

Основная задача проекта — найти метод, который стоит закрепить в скилле. Иногда достаточно одной настройки или шаблона. Тогда анализатор объяснит, почему отдельный скилл создавать не стоит, и предложит более простые рекомендации как дополнительную помощь.

Например: «Для этого разового объявления отдельный скилл не нужен: достаточно короткой инструкции по оформлению. Могу предложить более простые рекомендации для таких текстов».

## Как применить созданный скилл

Откройте новый рабочий чат, приложите полученный `.md` и новый материал. Напишите: «Примени приложенный скилл к этому материалу».

После создания анализатор подскажет, на какой следующей задаче использовать скилл, какие данные приложить и как оценить результат. Для разбора интервью это может быть новая расшифровка и проверка точности цитат, обоснованности выводов и необходимости повторно объяснять правила.

## Данные и контакты

Скиллы не отправляют переписки авторам проекта. Данные обрабатываются в выбранной вами ИИ-среде; её правила хранения и обработки продолжают действовать.
